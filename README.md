## ✨ Features

- **Instant Search:** Find any bookmark in seconds with a powerful, real-time search engine that works entirely on your device.
- **100% Private:** Your data never leaves your computer. No tracking, no data collection, no nonsense. See our [Privacy Policy](privacy_policy.md).
- **Works Offline:** Access and search your bookmarks even without an internet connection.
- **Simple & Clean UI:** A minimal and intuitive interface that gets out of your way.

### Manual Installation (For Developers)

1.  **Download** or **clone** this repository to your local machine.
    ```bash
    git clone https://github.com/abhishek-99ks/bookmark-finder.git
    ```
2.  Open Google Chrome and navigate to `chrome://extensions`.
3.  Enable **"Developer mode"** using the toggle switch in the top-right corner.
4.  Click on the **"Load unpacked"** button.
5.  Select the directory where you cloned or unzipped the project.
6.  That's it! The Bookmark Finder icon should now appear in your extension toolbar.

## 🚀 How to Use

1.  Click the **Bookmark Finder icon** in your Chrome toolbar.
2.  Alternatively, use a keyboard shortcut to open the search popup (e.g., `Ctrl+Shift+K`). You can configure this in `chrome://extensions/shortcuts`.
3.  Start typing to instantly filter through your bookmarks.
4.  Use the `Tab` and `Shift + Tab`to navigate the results in down and up directions respectively.
5.  Press `Enter` to open a bookmark in a new tab.
